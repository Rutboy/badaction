# Документация Badaction

Английская документация является источником истины. Русский и испанский
варианты — переводы, призванные упростить самостоятельный хостинг и участие в
разработке. Если перевод расходится с английской страницей или приложением,
руководствуйтесь поведением приложения и создайте обращение по документации.

## Использование и самостоятельный хостинг Badaction

- [Начало работы](getting-started.md) — запуск локального контейнерного стека или
  среды разработки из исходного кода.
- [Развёртывание](deployment.md) — настройка базовой production-конфигурации
  Compose, HTTPS-прокси, миграций и подключений PostgreSQL.
- [Конфигурация](configuration.md) — переменные среды выполнения, Compose и
  тестов.
- [Эксплуатация](operations.md) — проверка работоспособности, резервное
  копирование, восстановление, обновления, очистка по сроку хранения и
  восстановление владельца.
- [Диагностика](troubleshooting.md) — поиск типовых проблем с настройкой, базой
  данных, cookie и обновлениями в реальном времени.

## Архитектура и участие в разработке

- [Архитектура](architecture.md) — слои приложения, модель данных, модель
  доступа, обновления в реальном времени и фоновые задачи.
- [Безопасность и приватность](security-and-privacy.md) — границы доверия,
  хранимые данные, реквизиты, срок хранения и обязанности оператора.
- [Разработка](development.md) — структура репозитория, локальные проверки,
  тесты базы данных, миграции и скриншоты.
- [API браузера](api.md) — внутренний нестабильный HTTP-интерфейс веб-приложения.
