# Documentación de Badaction

La documentación en inglés es la fuente de verdad. Las páginas en ruso y
español son traducciones destinadas a facilitar el autohospedaje y las
contribuciones. Si una traducción difiere de la página en inglés o de la
aplicación, sigue el comportamiento de la aplicación y abre una incidencia de
documentación.

## Usar y autohospedar Badaction

- [Inicio rápido](quick-start.md) — el instalador guiado genera credenciales,
  instala Docker, inicia producción y configura HTTPS automático.
- [Primeros pasos](getting-started.md) — ejecuta el conjunto local de
  contenedores o un entorno de desarrollo desde el código fuente.
- [Despliegue](deployment.md) — configura la base de Compose para producción, el
  proxy HTTPS, las migraciones y las conexiones de PostgreSQL.
- [Configuración](configuration.md) — variables del entorno de ejecución,
  Compose y pruebas.
- [Operaciones](operations.md) — comprobaciones de estado, copias de seguridad,
  restauración, actualizaciones, limpieza de retención y recuperación del
  propietario.
- [Solución de problemas](troubleshooting.md) — diagnostica problemas habituales
  de configuración, base de datos, cookies y tiempo real.

## Entender el proyecto y contribuir

- [Arquitectura](architecture.md) — capas de la aplicación, modelo de datos,
  modelo de acceso, actualizaciones en tiempo real y trabajo en segundo plano.
- [Seguridad y privacidad](security-and-privacy.md) — límites de confianza, datos
  almacenados, credenciales, retención y responsabilidades del operador.
- [Desarrollo](development.md) — estructura del repositorio, comprobaciones
  locales, pruebas de base de datos, migraciones y capturas de pantalla.
- [API del navegador](api.md) — interfaz HTTP interna e inestable que utiliza la
  aplicación web.

Las políticas generales del proyecto están en
[Contribuir](../../CONTRIBUTING.md), [Seguridad](../../SECURITY.md),
[Soporte](../../SUPPORT.md) y el
[Código de conducta](../../CODE_OF_CONDUCT.md).
